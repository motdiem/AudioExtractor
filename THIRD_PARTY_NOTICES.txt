3. How the bundled ffmpeg was built
-----------------------------------

Both builds (macOS universal arm64+x86_64, Windows x64 cross-compiled with
mingw-w64) come from the scripts in the AudioExtractor source repository:

  https://github.com/motdiem/AudioExtractor
    scripts/ffmpeg/config.sh         versions, checksums and configure flags
    scripts/ffmpeg/build-mac.sh      macOS build
    scripts/ffmpeg/build-windows.sh  Windows build

The shared configure flags (config.sh), plus --arch, --target-os, --cc or
--cross-prefix and static-link flags for each platform, are:

  LAME:    --disable-shared --enable-static --disable-frontend
           --disable-decoder --disable-gtktest --disable-dependency-tracking

  FFmpeg:  --disable-everything --disable-autodetect --disable-doc
           --disable-debug --disable-network --disable-programs
           --enable-ffmpeg --disable-shared --enable-static
           --pkg-config-flags=--static --disable-avdevice --disable-swscale
           --enable-protocol=file,pipe
           --enable-demuxer=mov,matroska,mp3,aac,wav
           --enable-decoder=aac,mp3,mp3float,opus --enable-decoder='pcm_*'
           --enable-parser=aac,mpegaudio,opus --enable-bsf=aac_adtstoasc
           --enable-encoder=aac,libmp3lame,pcm_s16le --enable-libmp3lame
           --enable-muxer=ipod,mp4,mp3,null
           --enable-filter=aresample,aformat,anull,atrim,abuffer,abuffersink

Running `ffmpeg -buildconf` on the bundled binary prints the configuration it
was really built with.

Your rights under the LGPL include modifying FFmpeg and LAME and using your
own build. The app embeds the ffmpeg produced by `wails3 task ffmpeg:mac` and
`ffmpeg:windows`, so using a modified build means rebuilding AudioExtractor
from source with those scripts (`wails3 task release`).
